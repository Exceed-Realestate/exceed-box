# Exceed Box — 営業ダッシュボード（デモ）

Clickable concept demo of an Exceed sales dashboard: lead intake (business-card AI-OCR, CSV, GoHighLevel, SNS), step-mail nurturing, reaction scoring, booking flow with auto-assign, kanban pipeline, and a 30-second auto-play live demo.

Single self-contained `index.html` — no backend; all behavior simulated in-page. All names and numbers are dummy data.

Live: https://exceed-realestate.github.io/exceed-box/
